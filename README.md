# Color Code

Make `/color` in Claude Code theme the **whole session**, not just the prompt bar.

Run `/color yellow` and the session turns yellow: a yellow-tinted background, a
matching Claude Code theme, a re-lit terminal palette, and (in Windows Terminal)
the tab and the title bar. Every tab keeps its own color, so with several
Claude sessions open as tabs you can tell them apart at a glance.

## What you get

- **8 themes**, one per `/color` choice: red, orange, yellow, green, cyan, blue,
  purple, pink. `/color default` puts everything back.
- **Readable on purpose.** Each theme is generated with contrast checks: text,
  the model name, plan / auto-accept modes, tokens, warnings, errors and diffs
  all stay at least 4.5:1 against their own background. A color that shares the
  theme's hue (warning yellow on the yellow theme) is lifted so it never melts
  into the background or the prompt bar.
- **Per tab.** The Claude Code theme changes for that session only, and the
  terminal colors go to that tab only. Exit Claude and the tab resets.
- **Resume keeps it.** `claude --resume` / `claude -c` brings the session's
  color back.

## Install

At the prompt of a terminal session:

```
/plugin install color-code --marketplace roykersh/color-code
```

Answer `y` to add the marketplace, then pick the user scope. From the shell
instead:

```
claude plugin install color-code --marketplace roykersh/color-code
```

Sessions already open need a restart (`/exit`, then `claude -c`).

### Windows Terminal: color the tab and title bar too

Windows Terminal can't take a tab color from inside the tab, but it can make
tabs follow their own background. Add this theme to Windows Terminal's
`settings.json` (Settings → Open JSON file) and set `"theme": "Color Code"`:

```json
"themes": [
  {
    "name": "Color Code",
    "window": { "applicationTheme": "dark", "useMica": false },
    "tabRow": { "background": "terminalBackground", "unfocusedBackground": "terminalBackground" },
    "tab": { "background": "terminalBackground", "unfocusedBackground": "terminalBackground", "showCloseButton": "hover" }
  }
]
```

## Requirements and limits

- Windows with Windows Terminal (the terminal colors are sent by `bin/osc.exe`,
  a small helper built from `tools/osc.cs`). On other platforms the Claude Code
  theme half still works.
- Built for Claude Code's dark theme.
- When Windows Terminal reloads its settings it clears every tab's colors until
  the next `/color`.

## Customizing

Themes are generated by `tools/gen_themes.py`: edit the hues or contrast
targets there and run `python tools/gen_themes.py`. Rebuild the helper with
`csc /target:exe /out:bin\osc.exe tools\osc.cs` (the C# compiler that ships
with Windows under `C:\Windows\Microsoft.NET\Framework64\v4.0.30319`).

Set `COLOR_CODE_DEBUG=1` to have the plugin log each step to `debug.log`.
